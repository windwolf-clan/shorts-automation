2. What the application does

The application compiles C++ source files locally, captures the real output of the compiled programs, renders that source and output into short vertical videos with synthesized narration, and uploads the finished videos to a YouTube channel owned by the operator.

3. YouTube API Services

The application uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service and acknowledges the Google Privacy Policy.

The application accesses YouTube only to:

  • upload videos to the single channel the operator has authorized, and
  • read that same channel's own title and ID to confirm the correct account is connected.

It does not access, collect, store, or display data belonging to any other channel or viewer.

4. Acceptable use

The application is used in a manner consistent with YouTube's policies. In particular:

  • All uploaded content is original, created programmatically from the operator's own C++ source code.
  • Uploads go only to a channel the operator owns and has authorized.
  • The application does not scrape YouTube, automate the YouTube website, simulate user interaction, or attempt to circumvent any API quota or restriction.
  • Access is obtained exclusively through the official YouTube Data API with the operator's own OAuth authorization.
  • Upload volume is kept within the API quota allocated to the project.
