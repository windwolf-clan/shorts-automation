1. Summary

Shorts Automation Uploader is a personal command-line tool operated by one individual on their own computer. It has no server, no database, and no other users. It does not collect personal information from anyone, and it never transmits data to any third party.

2. Information the application handles

The only data involved is the operator's own Google authorization, obtained through Google OAuth 2.0:

  • OAuth access and refresh tokens — issued by Google to authorize uploads.
  • Basic channel information — the channel title and ID of the authorized channel, retrieved once to confirm the correct account is connected.

No other data is requested or received. The application does not access viewer data, comments, analytics, subscriber identities, watch history, or any other YouTube user's information.

3. Scopes requested and why

  • youtube.upload — required to upload generated videos to the operator's own channel.
  • youtube.readonly — used solely to read the authorized channel's own title and ID so the operator can confirm the correct channel is connected before uploading.

4. Where data is stored

Tokens are written to a local file named token.json on the operator's own computer. This file is never uploaded, synchronized, backed up to a remote service, or shared. It is excluded from version control. There is no remote storage of any kind because the application has no server.

5. How data is shared

Data is not shared. The application communicates only with Google's own YouTube Data API endpoints in order to perform the uploads it was built for. No analytics services, advertising networks, data brokers, or other third parties receive anything.

Data is not sold, rented, or transferred under any circumstances, and it is not used to build profiles or train models.

6. Retention and deletion

Tokens are kept only while the tool is in use. They can be removed completely at any time:

  • Delete the local file — removing token.json erases all stored authorization from the machine.
  • Revoke at Google — removing the application at myaccount.google.com/permissions invalidates the tokens on Google's side immediately.

Either action stops all access. Both together leave nothing behind.

7. YouTube API Services

This application uses YouTube API Services. Its handling of data obtained through those services is governed by the Google Privacy Policy, and use of the application is subject to the YouTube Terms of Service.

Authorized data is refreshed on each run rather than cached, and no YouTube data is stored beyond the authorization tokens described in section 2.

8. Children

The application is not directed at children, collects nothing from them, and is used only by its adult owner. Uploaded videos are marked as not made for children.
